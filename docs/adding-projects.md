# პროექტების დამატება MEGA-დან

სამუშაო წესი: ადმინისტრატორი წერს მოკლე მონაცემებს, Claude ამზადებს ფოტოებს და ქმნის პროექტს საიტზე.

## 1. რას წერს ადმინისტრატორი

თითო პროექტზე ასეთი ბლოკი (რამდენიმე პროექტი ერთად შეიძლება):

```
პროექტი: ბესტ ვესტერნი ქუთაისი
კატეგორია: სასტუმროები
MEGA: https://mega.nz/folder/iywFxQJS#pEe9RVEp-8mzohE7xkWMBA/folder/by5k1DpQ
მთავარი ფოტო: _IG_2420.JPG
ფოტოები: 12            ← არასავალდებულო, ნაგულისხმევად 12
ადგილმდებარეობა: ქუთაისი   ← არასავალდებულო
```

- **პროექტი**: სათაური ქართულად, ზუსტად ისე, როგორც საიტზე უნდა ჩანდეს.
- **კატეგორია**: ქართულად. თუ ასეთი კატეგორია ჯერ არ არსებობს, Claude შექმნის მას ინგლისური სახელითაც.
- **MEGA**: პროექტის საქაღალდის ბმული (MEGA-ში საქაღალდე → „Share link“ ან ბრაუზერის მისამართი).
- **მთავარი ფოტო**: ფაილის სახელი MEGA-დან. ის გახდება ბარათის ფოტო მთავარ გვერდსა და პროექტების სიაში.

## 2. რას აკეთებს Claude

1. **ინგლისური სათაური**: თარგმნის ან ტრანსლიტერაციას უკეთებს (ბრენდის სახელები რჩება ორიგინალში: „Best Western Kutaisi“, „სასტუმრო ხედი“ → „Khedi Hotel“). ინგლისური სათაურიდან კეთდება პროექტის გვერდის მისამართი (მაგ. `/projects/best-western-kutaisi`).
2. **კატეგორია**: ქართულს უსადაგებს არსებულს (ცხრილი ქვემოთ), ან ქმნის ახალს ქართული და ინგლისური სახელით.
3. **ფოტოები** (`scripts/mega-photos.mjs`):
   - `list` — ფოტოების სია; ამოწმებს, რომ მთავარი ფოტო საქაღალდეშია.
   - `sheet` — ყველა ფოტოს დანომრილი გადახედვის სურათი. Claude ათვალიერებს და ირჩევს საუკეთესოებს: სხვადასხვა ხედი და სივრცე, მკვეთრი და კარგად განათებული, მსგავსი კადრების გამეორების გარეშე.
   - `prepare` — მთავარი ფოტო + შერჩეულები, დამუშავებული ისევე, როგორც ადმინ პანელის ატვირთვისას: სწორი ორიენტაცია, მაქს. 2400px, WebP (ხარისხი 85), მეტამონაცემების (მაგ. GPS) გარეშე. გალერეაში მაქსიმუმ 30 ფოტოა.
   - ვიდეოებს და არა-ფოტო ფაილებს ტოვებს.
4. **საიტზე ატვირთვა** (production-ზე წვდომას საჭიროებს; ადმინისტრატორი ყოველ სესიაზე ადასტურებს):
   - ფოტოები იტვირთება Cloudflare R2-ში იმავე სტრუქტურით, რასაც ადმინ პანელი იყენებს (`gng/<წელი-თვე>/<uuid>.webp`).
   - პროექტი იქმნება ან ახლდება ბაზაში: სათაური (ქართ./ინგლ.), კატეგორია, მთავარი ფოტო, გალერეა, ადგილმდებარეობა; სტატუსი „გამოქვეყნებული“.
   - ბაზაში უკვე არის 25 საწყისი პროექტი (ზოგი ფოტოს გარეშე, მაგ. Best Western Kutaisi). თუ პროექტი უკვე არსებობს, ახალს არ ქმნის — არსებულს ავსებს, რომ ძველი მისამართი არ დაირღვეს და დუბლიკატი არ გაჩნდეს.
5. **შემოწმება**: ხსნის პროექტის გვერდს საიტზე და ამოწმებს ფოტოებსა და კატეგორიის ფილტრს.

ფოტოების ან სათაურის შეცვლა შემდეგ ადმინ პანელიდანაც შეიძლება (`/admin/projects`).

## ინსტრუმენტის გამოყენება

```bash
node scripts/mega-photos.mjs list    "<mega-ბმული>"
node scripts/mega-photos.mjs sheet   "<mega-ბმული>" --out <საქაღალდე>
node scripts/mega-photos.mjs prepare "<mega-ბმული>" --out <საქაღალდე> --cover _IG_2420.JPG --files _IG_2288.JPG,_IG_2300.JPG
node scripts/mega-photos.mjs prepare "<mega-ბმული>" --out <საქაღალდე> --cover _IG_2420.JPG --count 12
```

`--files` ირჩევს კონკრეტულ ფოტოებს; `--count` ფოტოებს თანაბრად ანაწილებს მთელ გადაღებაზე. შედეგი: `00-cover.webp`, `01.webp`, … და `manifest.json` (რომელი ფაილიდან რა მიიღო).
